# Focused Exam Finder

Type a presenting complaint and get a focused physical exam checklist, with page references to *Talley & O'Connor's Clinical Examination* (8th edn) and links to step-by-step technique guides.

Installable as a home-screen web app (Safari → Share → Add to Home Screen). Works offline after the first load.

Content is paraphrased for personal study; always check the cited textbook pages.
